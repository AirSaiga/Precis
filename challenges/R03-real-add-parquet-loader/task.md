# R03 — 新增 Parquet 数据源加载器（真实仓库导航）

| 项 | 值 |
|------|-----|
| ID | R03 |
| 类型 | 真实仓库导航 |
| 栈 | Python |
| 难度 | ★★★ |
| 预估 | 30-60 分钟 |

> 本题在**真实 Precis 仓库**上操作（不是 seed 最小工程）。你需要在数千个文件中
> 定位数据源加载系统的所有相关位置，理解它的注册机制，完成一种新数据源的全链路实现。
> 与最小 seed 题不同：没有给出任何文件路径，全部需要自己导航发现。

## 任务

Precis 后端支持多种数据源加载（CSV、Excel、JSON、SQL）。现在需要新增 `.parquet`
格式的完整支持。

该数据源必须**完全可用**：实现加载器、实现配置规格、注册到系统、能从配置字典构建规格、
能真正读出 Parquet 文件里的 DataFrame。

### 设计要点

- Parquet 是列式二进制格式，pandas 用 `pd.read_parquet(path, engine=...)` 读取。
  默认 engine 是 `pyarrow`（也可用 `fastparquet`）。加载时应允许通过 spec 配置 engine。
- 应支持限制读取行数（`nrows`，复用 `FileSourceSpec` 已有的同名字段语义）。
- 文件不存在、加载失败时，应抛出系统统一的加载异常（包裹原始异常），与其它加载器一致。

## 约束

- 在真实仓库代码里找到数据源系统的所有相关文件，完成**实现 + 注册**。
- **不得**修改 `challenges/` 目录、**不得**修改 `tests/` 目录（verify 脚本会自行放置测试文件）。
- 参考已有数据源（CSV / JSON）的实现模式——自己找。

  **关键提示：这个数据源系统有两个并行的目录结构。** 一个目录放"加载器"（负责把文件
  读成 DataFrame），另一个目录放"规格 / 配置"（描述一个数据源该怎么读，Pydantic 模型）。
  两侧各有自己的注册表，且各自用一个装饰器把类型登记进注册表。**两侧都要改**，
  遗漏任何一侧都会导致测试失败。

- 此外，每个目录都是一个 Python 包，有各自的 `__init__.py` 做延迟导入和重导出。
  新增的类要在对应的 `__init__.py` 里能被按名字取到（否则 `from ... import ParquetXxx`
  会失败）。

## 验证

在本目录运行：

```
python verify.py
```

`verify.py` 会把测试文件复制进后端测试目录并以 pytest 运行；随后还会以相同环境
**回归运行仓库既有的 loader/spec 测试子集**（规格模型与注册表、loaders 包
`__init__` 注册表与辅助函数、加载器基类、延迟导入边界、既有 CSV/Excel 加载器）。
注入测试与回归子集**都通过**才算 PASS。
退出码 `0` = PASS，非 `0` = FAIL。stdout 首行为 `PASS` 或 `FAIL`，
随后按 `  [✓]/[✗]` 列出注入测试与回归门明细。

> 测试会真正写一个临时 `.parquet` 文件并读回来校验数据。运行环境已预装 `pyarrow`；
> 若某机器没有 parquet 后端库，加载相关用例会自动 skip，但注册 / 规格 / 工厂构建
> 用例仍必须通过。

## 提示

- 找到一个数据源类型（如 `csv`）的全链路后，对照着把 `parquet` 走一遍即可。
  每个数据源类型在系统里出现的次数，就是你要改的文件数。
- 用全局搜索 `"csv"` 或 `"register_loader"` / `"register_source_spec"` 这类装饰器
  名字来定位注册点。
- 规格类继承自一个"文件规格基类"（它已经提供了 `path`、`mode`、`encoding`、`nrows`
  等通用字段），你只需加 Parquet 特有的字段（如 engine）。
- 加载器继承自一个抽象加载器基类，只需实现一个 `load()` 方法。
- `__init__.py` 里的延迟导入用的是模块级 `__getattr__` 钩子，新增类型要在那里加分支。
- **你的改动不得破坏仓库既有测试**（verify 会回归相关既有测试：规格/加载器注册表、
  包的延迟导入 `__getattr__`、加载器基类与既有 CSV/Excel 加载器行为）。接入新数据源时
  若破坏 `__getattr__` 分支、双注册表或基类契约，既有测试会红，整体判 FAIL。
