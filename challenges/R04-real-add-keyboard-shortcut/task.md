## 任务

Precis 前端有一个快捷键系统。新增 `Ctrl+Shift+F`（Mac 上 `Cmd+Shift+F`）快捷键，
触发 **「格式化画布」（format canvas）** 动作。

需要**完整实现**：

1. **命令定义** — 一个新的 `Command`，遵循现有命令的命名约定与字段结构。
2. **平台变体** — 同时给出 Mac（`Cmd+Shift+F`）与 Windows（`Ctrl+Shift+F`）变体。
3. **注册** — 把新命令接进默认命令的聚合出口，使其随快捷键系统自动注册。

自己找到快捷键系统的所有相关文件（命令定义、命令接口、平台适配、聚合/注册入口）。

## 快捷键语义

- 默认快捷键：`Ctrl+Shift+F`
- Mac 平台变体：`Cmd+Shift+F`（`meta + shift + f`）
- Windows 平台变体：`Ctrl+Shift+F`（`ctrl + shift + f`）

## 验证

在本目录运行：

```
node verify.mjs
```

`verify.mjs` 会把测试文件复制进前端测试目录并以 **vitest** 运行单个文件；随后还会
以相同环境**回归运行 keyboard 特性既有的 4 个测试文件**（`commandExecutor` /
`platformAdapter` / `platformDetector` / `shortcutRegistry`）。
注入测试与回归子集**都通过**才算 PASS。
运行后无论成败都会清理掉临时测试文件，不污染真实仓库。

退出码 `0` = PASS，非 `0` = FAIL。stdout 首行为 `PASS` 或 `FAIL`，
随后按 `  [✓]/[✗]` 列出注入测试与回归门明细。

> 注意：前端用 **vitest**（不是 jest）。测试用 `@/` 别名导入真实源码（与仓库内
> 现有键盘测试一致）。首次启动 vitest 较慢（约 15-25s），verify 对注入与回归
> 两次运行各设 90s 超时。

## 提示

- 快捷键命令按**类别**分文件组织；「格式化画布」属于画布类操作——找到画布类命令
  所在文件，照着里面的工厂函数加一个。
- 每个命令是一个工厂函数（`createXxxCommand`），文件末尾有一个聚合函数把该类别所有
  命令收集成数组——新命令既要写工厂，也要进聚合数组。
- 命令接口里有 `defaultShortcut` 与 `platformVariants.{mac,windows}` 两个字段，别只设默认
  快捷键而漏掉平台变体。
- 命令的 `execute` 是真实动作；测试**不执行**它，但会校验命令对象的字段完整性
  （`id` / `name` / `defaultShortcut` / `platformVariants` / `category` / `execute`）。
- 默认命令的总聚合在快捷键系统的主入口里（把三类命令展开合并的地方）——确认你的新命令
  能从该出口被遍历到。
